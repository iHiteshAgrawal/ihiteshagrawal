## Hi there 👋

Software engineer and AI researcher. I recently completed an R&D internship
at IIT Kharagpur, working on NLP and information retrieval with
Prof. Koustav Rudra, where I built a 75K+ item QA and multiple-choice
dataset from cryptocurrency video transcripts. I continue to coordinate
the cryptocurrency IR track at [FIRE 2026](https://fire.irsi.org.in/fire/2026/),
organised by IIT Kharagpur.

Alongside research, I have four years of production engineering experience
(2022–2026) — event-driven data pipelines, PostgreSQL performance work,
and REST/GraphQL APIs for a US-based fintech. Final-year CSE undergraduate,
largely self-taught.

**Interests:** responsible AI, NLP, information retrieval, computer vision.
